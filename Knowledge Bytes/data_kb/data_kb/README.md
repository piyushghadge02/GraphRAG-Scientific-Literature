# GraphRAG `data` Knowledge Bytes

This folder contains Knowledge Bytes for the two meaningful data areas found in the uploaded `data` directory:

- `raw/` — source corpus and PubMedQA context data.
- `processed/` — chunked corpus and evaluation artifacts.

`.gitkeep` files are not represented because they contain no application/data logic. The PNG is covered as a generated validation artifact inside `processed.md`.
